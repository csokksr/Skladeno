# Звірка з авторитетними джерелами

Не змінюй мовний чи фактичний зміст з пам'яті. Спершу знайди підтвердження тут.

| Що перевіряєш | Джерело | Як шукати |
|---|---|---|
| Правопис, дефіс/разом/окремо, велика літера | `research/pravopys/pravopys.pdf` (Український правопис 2026, 426 с.) | `python` + `pymupdf`: `get_text()` по сторінках, пошук за словом чи параграфом |
| Наголоси | `dist/web/files/officialDocs.1.data.pdf` (офіційний список наголосів) | так само |
| Теми й вимоги історії | `sources/program/hist.md` (програма, наказ МОН № 696) | `Grep` |
| Ключі завдань історії | `sources/keys/*.pdf`, `sources/keys/manual.json`, `sources/keys/mismatches.json` | `python tools/zno_keycheck.py` |
| Ключі української, математики, англійської | `sources/keys/zno2/*.pdf`, `sources/keys/zno2/manual.json`, `sources/keys/zno2/mismatches.json` | `python tools/zno2_keycheck.py` |
| Дати й події, яких немає в програмі | офіційні завдання в `src/history-bank.json` або перевірене джерело в інтернеті | якщо шукаєш в інтернеті, наведи URL у відповіді |

## Підтверджені правила (не «виправляй» їх назад)

- Окремо: «пів» + іменник у родовому (пів Києва, пів року, пів години).
- Разом: віце-, екс-, лейб-, обер-, міні- (віцепрем'єр, ексчемпіон, мініфутбол); веб- (вебсторінка).
- Через дефіс: жар-птиця, по-моєму, хтозна-хто, давним-давно.
- Офіційні написання: фоє́, Лук'ян; свято — День Незалежності України.

## Порядок

1. Знайди норму в джерелі й запиши сторінку або параграф.
2. Якщо джерело суперечить попередній версії, виправляй модулем `src/content/NN-*.json` і поясни в звіті, чому.
3. Не знайшов підтвердження — не змінюй і скажи про це користувачу.
4. Після змін: `python -I tools/build.py`, `python -I tools/validate.py`.

Для перевірки пачки питань делегуй субагенту `ukr-fact-checker`.
