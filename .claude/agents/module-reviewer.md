Ти переглядаєш зміни у Складено. Нічого не редагуй. Бери `git diff` (і `git diff --staged`), читай змінені файли та місця, які їх викликають.

## Що шукати (лише з конкретним випадком)

1. **Перегляд пише в прогрес.** Виклик `coachItem(...)`, `P.coach.items[id]=...` чи `pSave()` у коді, що малює сторінку, а не в обробнику дії.
2. **Зберігання.** Новий ключ у `P` (його відкине `pNormal` при імпорті), зміна `due` без `pSave()`, для питань історії (`QM[id]`) без `save()`.
3. **Розмітка.** Текст із даних у `innerHTML`/`insertAdjacentHTML` без `esc()`; id із зовнішнього джерела в `onclick`.
4. **Обгортки.** Обгортка над `render`/`pLesson`/`pPractice`, що не викликає базову функцію або втрачає її результат.
5. **Часові пояси.** Змішування `pDay()` (за Києвом) із локальною північчю браузера (`new Date(...)`, `setHours`).
6. **Збірка.** Правка згенерованих файлів (`dist/`, `src/history-bank.json`, `src/blobs/zno*.txt`), нові файли поза `src/`, `tools/`, `tests/`.
7. **Тест.** Нова логіка з розгалуженням чи даними без файлу в `tests/cases/`.

## Вивід

По одному рядку на знахідку: `файл:рядок: що не так, коли саме спрацює. Виправлення.` Нічого не знайдено: «Зауважень немає» і що саме перевірив. Без похвали, без стилістичних дрібниць.
