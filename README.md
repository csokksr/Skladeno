# Складено · підготовка до НМТ

Сайт — один HTML-файл, що працює без інтернету. Тепер його збирають з окремих джерел, щоб зміни було видно й легко редагувати.

## Команди

```bash
python -I tools/build.py      # зібрати dist/skladeno-nmt.html
python -I tools/validate.py   # перевірити всі завдання, посилання й тексти (код 0 лише при «OK»)
node tests/run.js             # регресійні тести сторінки (Node 18+; потрібна свіжа збірка)
```

## Сайт

Сайт публікується як приватний артефакт Claude (скіл `publish-web`); ділитися — через меню Share на сторінці.

```bash
python -I tools/build.py --web   # dist/web/: index.html + files/ (зображення, PDF) + offline/ (частини автономного файлу)
```

Веб-збірка додає `src/web/*.js`: діалог підтвердження замість `confirm()`, збереження файлів через `downloads`, PDF за посиланнями, синхронізацію прогресу через приватне сховище `db` (стиснений знімок у `data/users/<id>/progress*`). Оновлюючи сайт, публікуй `dist/web/index.html` на ту саму адресу; змінені файли з `files/` і всі нові `offline/*.txt` разом із `offline-manifest.json` додавай у тій самій або наступній публікації (не більше 64 МБ за раз).

Після зміни `tools/content_eng.py` чи `tools/content_ukr.py` запусти їх, потім `build.py`.

Банк завдань з історії складається лише з офіційних завдань ЗНО 2007–2021 і НМТ 2022–2026, набраних на zno.osvita.ua (57 тестів; авторські завдання й пояснення сайту не використовуються). Конвеєр:
1. `tools/zno_import.py` розбирає збережені сторінки `sources/zno/html` у `sources/zno/bank.json` (тип, варіанти, ключ, джерело).
2. `tools/zno_topics.py` призначає тему програми (Вступ + 31 розділ, наказ МОН № 696): за тематичними добірками сайту, решту — вручну в `tools/zno_overrides.json` (там же виключення й виправлені ключі).
3. `python tools/zno_images.py` (потрібен Pillow) завантажує зображення в `sources/zno/img` і зберігає стиснуті WebP у `src/blobs/zno-*.txt`.
4. `tools/zno_bank.py` пише `src/history-bank.json`; `build.py` після всіх модулів замінює ним згенеровані завдання історії, вилучає картки «L» і дублікати карток та прибирає посилання на зниклі ідентифікатори. Пробники з історії — справжні тести НМТ 2023–2026 у порядку оригіналу.

Справжні тести НМТ-2025 (`src/content/60-nmt2025.json` і `src/blobs/nmt2025.*`) генерує `tools/content_nmt2025.py <тека з PDF>`. Зошити й ключі варіанта 2 — з osvita.ua/test/answers/95541, 95542, 95543, 95547; варіант 1 не використано, бо в ньому біля завдань надруковано статистику й ключі.

## Формат `src/content/*.json`

- `merge` — замінити ключ у даних цілком;
- `extend` — дописати до списку верхнього рівня (наприклад, `ukrainianFiveOptionSets`);
- `topicQuestions` — завдання з полем `topicId`, додаються до теми предмета;
- `topicNotes` — `{topicId: [{title, text, example}]}`;
- `mockSets` — `{subject: [[32 id], …]}` для фіксованих варіантів (англійська);
- `explanations` — `{id: текст}`, заміна пояснення завдання;
- `patch` — `{id: {поле: значення}}`, точкове виправлення завдання;
- `factPatch` — `{factId: {поле: значення}}`, виправлення факту з історії (наприклад, `image`);
- `replace` — `[[старий, новий]]`, заміна тексту факту всюди, де його цитують (завдання, пояснення, картки);
- `drop` — `[id]`, вилучити завдання разом з усіма списками, що на нього посилаються;
- `addFacts` — `{topicId: [факт]}`, нові картки теорії історії; `dropFacts` — `[id]`, вилучити картки разом з усіма списками, що на них посилаються.

Модулі застосовуються за алфавітом назв файлів, тож пізніший файл бачить результат попередніх.

## Джерела шкали 100–200

Таблиці НМТ-2026 — Додаток 5 до Порядку прийому 2026 (PDF: osvita.ua/doc/files/news/978/97838/d5_1.pdf), звірені з education.ua і зі сторінкою osvita.ua/consultations/bachelor/86490/ (усі 140 значень збігаються, 2026-10-30). За шкалою 100–200 існують лише значення з таблиці (напр. для англійської є 191 і 200, але немає 195): цілі в плані й онбордингу — вибір лише з цих значень, збережені цілі приводяться до найближчого допустимого (`nmtValues`/`nmtSnap` у `src/modules/10-study.js`, тест `tests/cases/nmt-targets.js`). Для НМТ-2027 таблиці потрібно оновити в `src/content/10-nmt-scale.json`, щойно МОН їх затвердить.

## Безпека

Сайт статичний: без сервера, акаунтів, паролів, API-ключів, змінних середовища й бази даних. Прогрес лежить у `localStorage` браузера (у веб-версії ще в приватному підпросторі `data/users/<uid>/` артефакта).

- Весь користувацький текст і значення з імпорту копії йдуть у розмітку через `esc()`; імпортована копія проходить `pNormal` + `guardPlatform` (`src/modules/15-import-guard.js`): id за шаблоном, заголовки без `<>`, часи — лише числа.
- Автономний файл має Content-Security-Policy у `src/shell.html` (без мережі, крім свого джерела; `unsafe-inline` потрібен, бо обробники подій вбудовано). У веб-версії заголовки та CSP задає сам claude.ai: артефакт їх не змінює.
- `python -I tools/validate.py` шукає у власному коді ключі, `eval`, `document.write`, `console.log`; має завершитися «OK».
- Dev-сервери з `.claude/launch.json` слухають лише `127.0.0.1`.
- Залежності лише для `tools/`: `requirements.txt` (pymupdf, pillow).

## Сумісність

Нижня межа браузерів: Chrome/Edge 98, Firefox 98, Safari 15.4 (використано `structuredClone`, `Object.hasOwn`, `Array.prototype.at`). У коді немає regexp з lookbehind, тож Safari 15.4–16.3 теж працює; `validate.py` не пропустить `eval`, `document.write`, `console.log`.

## Що перевірено й що ні

- Ключі звірені з усіма офіційними аркушами УЦОЯО зі списків `sources/keys/list.txt` і `zno2-list.txt` (повний прогін 2026-10-29, 0 розбіжностей): історія — 1215 із 2925 завдань (ЗНО 2010, 2011, 2015–2021, НМТ 2022–2026 з демо), українська/математика/англійська — 2228 із 3477. Не звірено: решту історії (ЗНО 2007–2014, пробні тести; офіційних PDF з ключами для них не знайдено) і решту zno2 (пробні тести та ЗНО 2007–2010). Аркуші лежать поза git (`sources/keys/*.pdf`, завантажуються за списками); `zno_keycheck.py` для НМТ-2026 демо потребує ще `dist/web/files/…` (після `build.py --web`). `zno2012-s1` … `zno2014-dod` зі списку — не аркуші ключів, а програмні буклети.
- Тексти офіційних завдань виправляє `build.py`: слова зі змішаними літерами кирилиці й латиниці (`нa`, `ХVІІ`, `Нow`) приводяться до одного алфавіту (римські цифри — латиниця), м'які переноси прибираються; формули `⟦…⟧` не чіпаються. Завдання-про-букви (`zu-21254`, `zu-15199`) лишаються як є.
